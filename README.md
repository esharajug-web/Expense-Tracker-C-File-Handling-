# 💸 Expense Tracker (C++)

A simple command-line based Expense Tracker built using C++. This project allows users to record, view, and calculate their expenses efficiently using file handling.

---

## 🚀 Features
- Add new expenses with category and amount  
- View all recorded expenses  
- Calculate total spending  
- Data stored permanently using file handling  

---

## 🛠️ Technologies Used
- C++  
- File Handling (fstream)  
- Object-Oriented Programming
